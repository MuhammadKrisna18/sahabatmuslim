# Sahabat Muslim 🕌

Selamat datang di aplikasi **Sahabat Muslim**! Aplikasi ini dirancang khusus untuk menemani ibadah harian Anda agar menjadi lebih mudah, nyaman, dan khusyuk.

## ✨ Fitur Utama
- **📖 Al-Quran Digital:** Membaca Al-Quran lengkap 114 surah dengan teks Arab yang jelas, tulisan Latin, serta terjemahannya.
- **🎧 Murottal Audio:** Dengarkan lantunan suci Al-Quran dari berbagai Qori pilihan terbaik di dunia, termasuk Syeikh Alaa Aqel.
- **📶 Mode Offline (Tanpa Internet):** Unduh audio surah pilihan Anda ke dalam HP agar bisa diputar kapan saja tanpa perlu khawatir kehabisan kuota internet.
- **🌙 Mode Khusyuk (Zen Mode):** Baca Al-Quran dengan layar penuh tanpa gangguan tombol. Cocok untuk Anda yang sedang fokus tadarus atau menghafal.
- **📌 Penanda Ayat:** Simpan ayat yang terakhir dibaca agar Anda tidak lupa dan mudah melanjutkannya di lain waktu.
- **🔔 Pengingat Adzan:** Membantu Anda untuk selalu tepat waktu dalam melaksanakan shalat lima waktu.

## 📚 Sumber Data yang Digunakan
Aplikasi ini dikembangkan dengan niat baik (dakwah) dan didukung oleh layanan-layanan hebat yang terbuka untuk umat:
- **Audio Murottal Utama (Qori 1 hingga 8):** Didukung oleh **[MP3Quran.net](https://www.mp3quran.net)**. Mereka menyediakan layanan dan server audio secara gratis bagi siapa saja yang ingin membuat aplikasi Al-Quran.
- **Audio Syeikh Alaa Aqel:** Disimpan dan dikelola secara aman oleh **[Archive.org](https://archive.org/details/AlaaAql)**, sebuah perpustakaan digital global non-profit yang menjaga karya-karya publik agar bebas diakses oleh siapa saja.

*(Semua sumber di atas bersifat terbuka, gratis (Open Source / Public Domain), dan 100% aman digunakan tanpa khawatir pelanggaran hak cipta, selama aplikasi ini digunakan dengan etika yang baik.)*

## 🚀 Cara Menjalankan (Untuk Developer)
Jika Anda adalah *developer* yang ingin mencoba menjalankan kode ini:
1. Pastikan komputer Anda sudah terpasang [Flutter](https://flutter.dev/).
2. Unduh (*clone*) *source code* ini ke komputer Anda.
3. Buka terminal di dalam folder proyek, lalu ketik `flutter pub get` untuk mengunduh semua perlengkapan.
4. Ketik `flutter run` untuk menyalakan aplikasi di HP atau Emulator.
